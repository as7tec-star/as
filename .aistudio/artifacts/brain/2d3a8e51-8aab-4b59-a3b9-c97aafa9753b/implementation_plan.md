# مركز عملي (My Business Hub) - نظام إدارة المبيعات والتسويق الذكي

تطبيق أندرويد متكامل ومصمم بالكامل باللغة العربية (RTL) لإدارة العملاء، مهام المتابعة اليومية، توليد محتوى تسويقي احترافي متعدد المنصات بواسطة الذكاء الاصطناعي Gemini، وإطلاق حملات التواصل عبر واتساب وجيميل مع إحصائيات بيع دقيقة.

---

### User Review & Critical Decisions

> [!IMPORTANT]
> **القرارات المؤكدة من مرحلة الاستيضاح**:
> - **نمط العرض**: واجهة رأسية مُحسنة خصيصاً للهواتف الذكية مع تجربة استخدام سلسة وأنيقة وقابلة للتكيف.
> - **تخزين البيانات**: سحابة Firebase (Firestore + Google Sign-In) لمزامنة فورية ومستمرة وحماية بيانات العملاء والمنتجات من الضياع، مع كاش محلي فوري.
> - **توليد النصوص بـ Gemini**: إمكانية التبديل المباشر بين اللهجة الدارجة (البيضاء/الخليجية المناسبة لحراج وتيك توك) والفصحى التسويقية المهنية.

---

### 1. Overview & Core Concept

- **طبيعة التطبيق**: نظام CRM وتسويق مصغر وشامل لأصحاب الأعمال، المتاجر الإلكترونية، والمسوقين المستقلين عبر منصات التواصل والإعلانات المبوبة في العالم العربي (حراج، مرجان، تيك توك، فيسبوك، واتساب).
- **الجمهور المستهدف**: التجار، مندوبو المبيعات، أصحاب المشاريع الصغيرة، والوسطاء التجاريون الذين يحتاجون متابعة سريعة للعملاء وتوليد إعلانات جذابة دون فوضى الملاحظات اليدوية.
- **القيمة الأساسية**: تسريع إغلاق الصفقات، منع تسرب العملاء عبر التذكير التلقائي بالمتابعة، وأتمتة كتابة الإعلانات والرسائل التسويقية لكل منصة بدقة وبنقرة واحدة.

---

### 2. User Experience & Visual Design

#### Key User Flows

1. **إدارة العملاء وتدفق المبيعات (Clients & Pipeline)**:
   - التبديل السلس بين عرض **Kanban (لوحة مسار المبيعات)** بالأعمدة (جديد، تم التواصل، مهتم، تفاوض، تم البيع، خسرناه) مع نقل العميل بين المراحل بضغطة زر أو سحب، وعرض **الجدول البديل** الغني بالبيانات.
   - تصفية فورية حسب المصدر (حراج، مرجان، تيك توك، فيسبوك، واتساب، أخرى) والبحث السريع بالاسم ورقم الهاتف.
   - بطاقة تفاصيل شاملة للعميل: سجل التواصل، الملاحظات، معلومات الاتصال، وقيم المبيعات.

2. **المتابعة الذكية ومهام اليوم (Daily Follow-ups)**:
   - تبويب "مهام اليوم" يكتشف تلقائياً العملاء الذين تجاوز آخر تواصل معهم 3 أيام (مع إمكانية ضبط عدد الأيام من الإعدادات).
   - زر سريع بنقرة واحدة لجدولة تذكير أو حدث في تقويم جوجل (Google Calendar) أو تطبيق المهام (Android Calendar/Tasks Intent) لكل عميل.

3. **النشر متعدد المنصات وتوليد Gemini (Multi-Platform Ad Studio)**:
   - إدخال بيانات السلعة أو الخدمة: الاسم، السعر، الوصف، المدينة، والوسائط.
   - توليد متوازي وفوري بالذكاء الاصطناعي مع إمكانية اختيار نبرة النص (دارجة بيضاء / فصحى مقنعة):
     - **حراج ومرجان**: عنوان جذاب، وسعر ووصف بصيغة مبوبة واضحة وشروط التواصل.
     - **تيك توك**: نص خاطف وسيناريو فكرة فيديو مقترحة مع هاشتاقات نشطة.
     - **فيسبوك**: منشور تسويقي عاطفي وجذاب يشرح المزايا والدعوة لاتخاذ إجراء (CTA).
     - **واتساب**: رسالة برودكاست قصيرة ومباشرة مع رابط المحادثة.
   - لكل بطاقة زر "نسخ النص" وزر "فتح المنصة" الذي يطلق التطبيق أو الموقع مباشرة.
   - جدول مراقبة الإعلانات وحالاتها (لم ينشر، نُشر، يحتاج تجديد) مع عداد تنازلي للتجديد بعد عدد أيام محدد وتقويم محتوى للمنشورات المجدولة.

4. **المراسلة والحملات التسويقية (Messaging & Campaigns)**:
   - قوالب جاهزة (ترحيب، متابعة عميل متردد، عرض سعر مخصص، شكر بعد البيع، تذكير بعرض خاص).
   - صياغة ذكية بالذكاء الاصطناعي تدمج اسم العميل وحالته الحالية واحتياجه الفعلي.
   - زر مباشر يفتح واتساب برقم العميل ورسالة جاهزة عبر رابط `wa.me` وتطبيق واتساب.
   - زر "مسودة في Gmail" لفتح تطبيق البريد مع تعبئة العنوان والرسالة الجاهزة.
   - حملة الرسائل: فلترة مجموعة من العملاء (مثلاً كل فئة "مهتم") وتوليد رسائلهم لتنفيذ الإرسال اليدوي المباشر والآمن بنقرة لكل عميل.

5. **لوحة الإحصائيات (Analytics & Conversion)**:
   - بطاقات إحصائية رئيسية: عدد العملاء الجدد هذا الأسبوع والشهر، معدل التحويل إلى "تم البيع" (Conversion Rate).
   - تحليل بياني لأفضل مصادر العملاء جذباً ومقارنة أداء القنوات.

#### Visual Identity & Theme
- **التوجه البصري**: أسلوب عصري هادئ وبسيط (Modern Executive Minimalist) يريح العين أثناء العمل المكتبي والميداني.
- **لوحة الألوان**:
  - الأساسي (Primary): أزرق بحري عميق احترافي (`#1A365D` / `#2B6CB0`).
  - الثانوي (Secondary): تيل زمردي هادئ للنجاح والتحويلات (`#2C7A7B` / `#319795`).
  - الخلفيات (Background & Surface): درجات رمادية دافئة وفاتحة جداً (`#F7FAFC` / `#FFFFFF`) مع تباين ناعم للبطاقات، وظلال خفيفة لمنح عمق حقيقي دون صخب.
  - حالات العملاء بألوان مميزة ومتناسقة:
    - جديد: رمادي/أزرق ناعم.
    - تم التواصل: أصفر عنبري ناعم.
    - مهتم: أرجواني هادئ.
    - تفاوض: برتقالي دافئ.
    - تم البيع: أخضر زمردي مريح.
    - خسرناه: وردي محايد خافت.
- **الخطوط والطباعة**: خط عربي نظيف عالي الوضوح (Cairo / Tajawal / System Arabic Font) مع أوزان واضحة للعناوين والأرقام.

### 3. Key Product Decisions & Trade-Offs

- **المزامنة والتخزين السحابي (Firebase Firestore + Google Sign-In)**:
  - *القرار*: استخدام Firebase Firestore لحفظ كافة العملاء والمنشورات والحملات في السحابة مع دعم الحفظ المحلي التلقائي عند انقطاع الإنترنت.
  - *المبرر*: تلبية مباشرة لرغبة المستخدم في حماية البيانات ومنع ضياعها، مع التوافق التام مع ضوابط البيئة وتوفير Google Sign-In المعتمد.
- **توليد الذكاء الاصطناعي (Firebase AI Logic / Gemini)**:
  - *القرار*: استخدام نموذج Gemini 2.5 Flash أو Gemini 1.5 عبر مكتبة Firebase AI Logic لتوليد الإعلانات والرسائل بمرونة وسرعة فائقة.
  - *المبرر*: سرعة الاستجابة، دقة فهم السياق التجاري العربي (السعودي والخليجي والعام)، والتنقل بين العامية والفصحى بسلاسة.
- **التكامل الخارجي الآمن (Safe External Dispatch)**:
  - *القرار*: استخدام روابط Android Intents الرسمية وتنسيق `wa.me/phone?text=...` بدلاً من أي سكربتات خارجية غير آمنة أو قد تحظر الحسابات.
  - *المبرر*: احترام متطلبات المستخدم بعدم استخدام نشر آلي مباشر، والاعتماد على تجهيز المحتوى الدقيق وتسليم التحكم التام للمستخدم.

### 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Jetpack Compose (RTL UI)                       │
├────────────────────────────────────────────────────────────────────────┤
│  Top Bar: عنوان الشاشة + مؤشر المزامنة + زر إضافة عميل/إعلان           │
│  Navigation: شريط سفلي متين بـ 5 أقسام رئيسية                          │
│   ├── [1] العملاء (Kanban / جدول)                                      │
│   ├── [2] مهام اليوم (المتابعات المتأخرة + تذكيرات Calendar/Tasks)     │
│   ├── [3] استوديو الإعلانات (توليد Gemini + مراقبة النشر والمواعيد)   │
│   ├── [4] حملات المراسلة (قوالب + واتساب wa.me + مسودات Gmail)        │
│   └── [5] لوحة الإحصائيات (نسب التحويل + مصادر العملاء + مؤشرات)       │
└─────────────────────────────────┬──────────────────────────────────────┘
                                  │ StateFlow & Events
┌─────────────────────────────────▼──────────────────────────────────────┐
│                              ViewModels                                │
│   - ClientsViewModel (إدارة العملاء، الفلترة، الحالات)                 │
│   - FollowUpViewModel (حساب أيام المتابعة، مهام اليوم، التقويم)         │
│   - AdStudioViewModel (توليد Gemini، مراقبة التجديد، تقويم النشر)       │
│   - MessagingViewModel (صياغة الرسائل، روابط WhatsApp، Gmail)          │
│   - AnalyticsViewModel (حساب نسب التحويل، المصادر، المؤشرات)           │
└─────────────────────────────────┬──────────────────────────────────────┘
                                  │
┌─────────────────────────────────▼──────────────────────────────────────┐
│                            Repositories                                │
│   - ClientsRepository <---> Firebase Firestore / Room Data Store       │
│   - AdPostsRepository <---> Firebase Firestore                         │
│   - AiGenerationRepository <---> Firebase AI Logic (Gemini API)        │
└────────────────────────────────────────────────────────────────────────┘
```

#### الكيانات الأساسية (Data Models):
- **Client**: `id`, `name`, `phone`, `email`, `source` (Haraj, Mourjan, TikTok, Facebook, WhatsApp, Other), `status` (New, Contacted, Interested, Negotiating, Won, Lost), `notes`, `lastContactDate`, `createdAt`, `dealValue`.
- **AdPost**: `id`, `title`, `price`, `description`, `city`, `images`, `generatedVersions` (Haraj, TikTok, Facebook, WhatsApp), `platform`, `status` (Unpublished, Published, NeedsRenewal), `postUrl`, `publishedAt`, `renewalDays`, `scheduledDate`.
- **MessageTemplate**: `id`, `title`, `type` (Welcome, FollowUp, PriceQuote, ThankYou, Reminder), `templateText`.
- **Campaign**: `id`, `name`, `targetStatus`, `generatedMessagesMap`, `sentClientsList`, `createdAt`.

### خطة البناء والمراحل (Execution Phasing)

1. **المرحلة الأولى: البنية التحتية والبيئة الأساسية**:
   - إعداد هوية التطبيق في `metadata.json` و `strings.xml`.
   - تنفيذ تدفق التوثيق وربط Firebase والتأكد من إعدادات الحفظ السحابي.
   - بناء الثيم والألوان الداعمة للعربية مع محاذاة RTL والطباعة المناسبة.
2. **المرحلة الثانية: إدارة العملاء والمتابعة (الأقسام 1 و 2)**:
   - شاشة عرض العملاء بقناتي الـ Kanban التفاعلي والجدول المنسق.
   - مربع حوار إضافة وتعديل وحذف العملاء مع التحقق من صحة أرقام الهواتف.
   - قسم "مهام اليوم" مع احتساب فترة الـ 3 أيام وتوليد أحداث التقويم والمهام عبر Intent.
3. **المرحلة الثالثة: النشر متعدد المنصات والذكاء الاصطناعي (القسم 3)**:
   - نموذج إدخال المنتج / الخدمة.
   - محرك توليد الإعلانات بـ Gemini مع دعم اللهجة الدارجة والفصحى لكل منصة.
   - إدارة حالة المنشورات وروابط المنصات وإشعارات التجديد وتقويم المحتوى.
4. **المرحلة الرابعة: المراسلة والحملات والإحصائيات (الأقسام 4 و 5)**:
   - قوالب الرسائل وتوليد الرسائل المخصصة باسم وحالة العميل.
   - إطلاق واتساب مباشرة وتجهيز مسودات البريد الإلكتروني.
   - حملة الرسائل الموجهة للشرائح مع تنفيذ إرسال تتابعي آمن.
   - لوحة إحصائيات المبيعات، معدل التحويل، ومصادر العملاء برسوم تفاعلية واضحة.
